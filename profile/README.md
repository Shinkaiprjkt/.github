Welcome to Shinkai Project!!
===========

### Based on Android Open Source Project and [PixelOS](https://github.com/PixelOS-AOSP) Releases 16.2

project shinkai is a pixel rom with some extra features

### Beginner guide
 
1. If you want to build Shinkai Project, [DM me on telegram](https://t.me/Mnskkyy) with your github username
2. Use this [commit](https://github.com/Mnskkyy/device_xiaomi_rosemary/commit/4e6109c11433dd559406e04dc692c6c770b077fc) as a reference to make a Bringup Shinkai Project!!
3. Use the ```mka shinkai -j$(nproc --all)``` command to start your build.

Good luck in your compilation :)
